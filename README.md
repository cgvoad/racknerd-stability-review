## 稳定从哪来：KVM 隔离、RAID-10 和基本不超售的 CPU

RackNerd 的稳定性靠的是几个结构性因素，不是运气。

首先是 KVM 全虚拟化。内存和 CPU 是划给你的独立资源，同一台物理机上的邻居再怎么吃资源，影响不到你的份额。那份 6 个月的测试报告里明确写了：全程没遇到“吵闹邻居”问题。

其次是 CPU 几乎不超售。同一台机器反复跑 Geekbench 6，单核分数波动只有 3–5%。超售严重的商家，这个数字会难看得多，高峰期掉一半都不稀奇。存储端用 RAID-10 阵列的 SSD，条带加镜像，坏一块盘数据不丢；三地机器 12 个月的 dd 磁盘测试稳定在 480–520 MB/s，存储层没有偷工减料。

机房层面，它的服务器部署在 ColoCrossing 等合作机房里，每个节点维护独立的服务器资源，机房有多运营商 BGP 和冗余供电。网络实测也撑得住：1 Gbps 端口跑出 920–950 Mbps 的真实吞吐，12 个月没发现限速。

短板也要说清楚：全系是传统 SSD，不是 NVMe，4K 随机读写大约 2.5 万 / 1.8 万 IOPS，比 NVMe 机型差一截。跑数据库密集型应用的话，这一点要有预期。
